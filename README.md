# Student-Log
# FEATURES
  ~Add students
 
  ~Add or update exam marks
 
  ~View student list
 
  ~View complete student records
 
  ~Add and remove subjects
 
  ~Calculate total marks, percentage, and result
 
  ~Automatically save data using JSON
  
  ~Basic input validation and error handling
# TOOLS USED
  ~Python 3
  
  ~JSON

  ~File handling

  ~Functions, lists and Dictionaries
 
  ~Exception Handling
# HOW TO RUN
  Use the repository and run:
  python Main.py

  The program automatically creates and updates student_data.json to store the data.
